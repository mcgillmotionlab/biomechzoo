biomechzoo
==========

**biomechzoo** is a Python toolbox for processing and analysing biomechanical
motion capture data. It provides a unified data structure (the *zoo* format)
and a collection of functions for loading, filtering, normalising, visualising,
and statistically summarising kinematic and kinetic time series.
